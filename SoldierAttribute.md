# Soldier Attribute Information
Rage, Range, Move Range, Marching SPD, Crop Consumption, and Cost Coefficient(Ratio of cost value for recruiting, upgrading, and healing) value is fixed for each soldier, can't be modified by upgrade unless there is hero with specific buff to that attribute. Only HP, ATK, and Skill that can be upgraded its value with training this soldier into higher level. Comparison value between lvl 1-6 symbolized with [ ]. For Rage value value1/value2 means initial rage of this soldier when entering battle was value1, amount needed for this soldier to unleash their skill is value2 and after unleashing skill, this soldier rage was reset to 0 unless there are hero expertise that buffing this soldier rage after skill.
Spearman > Cavalry > Shieldman > Bowman > Spearman again. > mean this type soldier having advantage for fighting this soldier type. If any of this soldier type are countering this kind, they will receive 40% bonus ATK and ignoring their 20% DMG Reduction when attacking them, and if this soldier attacked by them, their ATK will reduced 40%.
Example Spearman are counter for Cavalry, they will get 40% bonus ATK and ignoring 20% DMG Reduction when attacking cavalry, and if cavalry attacked spearman then Cavalry ATK -40%.
